DHTML (Dynamic HTML)

Combines HTML, CSS and JavaScript to create dynamic webpages. It empowers web browsers to modify page content, layout and visual appearance dynamically on the client side.

HTML + CSS + JavaScript

🖱️

onclick Event

Switches between two images when clicked. The event listener detects the click trigger and immediately updates the DOM img.src attribute with smooth visual transitions.

element.onclick / addEventListener

mouseover and mouseout

mouseover and mouseout: Changes and restores text styling when the mouse enters or leaves. By intercepting cursor movement, DHTML directly alters CSS font styles, colors, and shadows on the fly.
