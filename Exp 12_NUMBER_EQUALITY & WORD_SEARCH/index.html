How It Works

Key JavaScript concepts utilized in this educational analyzer.

===
Concept 01

Number Comparison Using ===

The strict equality operator (===) verifies both numerical value and data type without performing implicit type coercion. When both numbers evaluate to identical values (including positive, negative, and floating-point decimal numbers), the condition returns true.

if (num1 === num2) {
  // Both numbers are equal!
}

Concept 02

Array Storage & Zero-Based Indexing

JavaScript arrays hold an ordered list of items accessible through contiguous integer indices. Numbering starts at zero, so the first element "Learning" sits at index 0, followed by index 1, 2, and so forth.

const words = ["Learning", "JavaScript", ...];
words[0] === "Learning"; // true

Concept 03

Word Position Identification using indexOf()

The indexOf() method inspects the array for a target item. If found, it returns the exact zero-based position (0 or higher). If the item is absent, it returns -1. Case-insensitivity is achieved by comparing uniform lowercased representations.

const index = wordsArray.indexOf("JavaScript");
// Returns index: 1 (or -1 if missing)
