Assignment Architecture & Technical Features

Core JavaScript concepts implemented in this application
AJAX & XMLHttpRequest

Asynchronous Client-Server Protocol

Real-time communication with the Express backend using native XMLHttpRequest. Handles readyState === 4, checks status === 200, and uses callback functions for clean asynchronous flow.

RegExp Validation

Client & Server Validation

City inputs are rigorously evaluated with JavaScript Regular Expression /^[a-zA-Z\s\-']{2,60}$/, protecting against numbers, invalid punctuation, empty strings, and script injection.

JSON.parse & Structuring

Structured Object Architecture

Processes raw server responses with JSON.parse() wrapped in try...catch, extracting city, coordinates, temperature, humidity, wind, and sunrise data into a structured state object.

DHTML DOM Manipulation

Dynamic Updates Without Reload

Zero full-page reloads. All cards, indicators, weather icons, unit switches (°C/°F), and timestamps are modified dynamically using high-performance DOM manipulation methods and CSS animations.
