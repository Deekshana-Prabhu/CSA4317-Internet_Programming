Biosensors & Wearables

Sensors detect physiological electrical/photoplethysmographic signals, convert analog bio-signals to digital telemetry, and transmit over BLE or Zigbee.

Edge Gateway

Edge hub aggregates sensor readings, executes protocol translation (BLE to MQTT/JSON), manages local packet buffering during outages, and handles device encryption.

Ingestion & Storage

High-throughput MQTT broker ingests incoming packets, validates schemas, writes records to time-series DB, and fires threshold alerts asynchronously.

Clinical Dashboard

Web application receives real-time updates via WebSockets/Socket.IO, rendering instant clinical vitals, anomaly charts, and notification alarms for physicians.

M2M Reliability & Edge Offline Buffering Lab

Demonstrates how edge devices buffer biometric data when connection drops and flush the queue in FIFO order upon reconnection with zero data loss.

Reliability Mechanism Details
1. Message Buffering: Telemetry frames are queued in non-volatile flash RAM when transport drops.
2. Exponential Backoff: Reconnection attempts employ jittered exponential backoff to prevent network congestion storms.
3. Duplicate Prevention: Each packet holds a monotonic UUIDv4 to eliminate duplicate ingestion.
4. Strict Ordering: High-precision UTC timestamps preserve chronological integrity.

Healthcare Security & Patient Privacy Architecture
HIPAA & GDPR Framework Concept
1. End-to-End Encryption

All M2M payloads are encrypted at the edge with AES-256-GCM. Ingestion channels enforce TLS 1.3 mutual certificate pinning.

2. Role-Based Access Control

Strict segregation ensures doctors access only assigned cohorts, while patient roles access exclusively their personal telemetry records.

3. Device Mutual Authentication

Each medical biosensor possesses an X.509 hardware certificate validated by Edge-GW-01 before packets are accepted.
