Core Engine

Role of Apache Web Server

Apache sits at the gateway of your web architecture, translating raw network traffic into structured web page deliveries.

The Request-Response Lifecycle

Follow how an HTTP request travels from the user's browser, through Apache and backend processors, and back as a rendered web page:

1
User Enters URL
User enters a website address (e.g. http://localhost/index.php) in the browser address bar.
2
Browser Sends Request
Browser establishes a TCP connection and transmits an HTTP GET or POST request across the network.
3
Apache Receives Request
Apache listens on Port 80 (HTTP) or Port 443 (HTTPS), parses request headers, and checks VirtualHost configurations.
4
Routing & Static Delivery
Apache serves static files (.html, .css, images) immediately, or hands dynamic .php files to the PHP module.
5
PHP & MySQL Processing
PHP processes code logic and communicates with MySQL when database access or user verification is required.
6
Response Delivered
Apache packages the dynamically generated HTML and sends an HTTP 200 OK response back to the browser for rendering.

Step-by-Step

Installation Guides

Follow practical, tested installation steps for both Ubuntu Linux (LAMP) and Windows (WAMP).

Ubuntu Linux Installation Checklist
Check off commands as you execute them
0 of 6 (0%)
Step 1: Update packages
Terminal

Synchronize package index files from remote repositories.

sudo apt update
Step 2: Install Apache
Web Server

Install Apache HTTP Server daemon and default configuration.

sudo apt install apache2
Step 3: Install MySQL
Database

Install MySQL server package for relational database storage.

sudo apt install mysql-server
Step 4: Install PHP
Language & Modules

Install PHP runtime, Apache integration module, and MySQL driver.

sudo apt install php libapache2-mod-php php-mysql
Step 5: Restart Apache
Systemctl

Restart web server daemon so newly installed PHP modules take effect.

sudo systemctl restart apache2
Step 6: Test installation
Verification

Open http://localhost in your web browser. You should see the standard Apache2 Ubuntu Default Welcome Page.

Note on Linux Distributions: Commands shown above target Ubuntu / Debian. Package manager commands and package names may vary across distributions (e.g., RedHat/CentOS use sudo dnf install httpd mariadb-server php, while Arch Linux uses sudo pacman -S apache php mysql).
Windows WampServer Checklist
Track your Windows setup milestone progress
0 of 7 (0%)
Step 1: Download WampServer
Download

Download WampServer from its official portal. Choose the 64-bit (x64) or 32-bit (x86) version matching your Windows OS.

Official WampServer Website (https://www.wampserver.com/en/)
Step 2: Install Microsoft Visual C++ Redistributables
Prerequisite

Install the required Microsoft Visual C++ redistributables (VC9, VC10, VC11, VC13, VC14, VC17) if prompted. Apache and PHP binaries require these C++ runtimes on Windows.

Step 3: Run the WampServer installer
Setup Wizard

Right-click the downloaded setup file and select Run as administrator to initiate the installation wizard.

Step 4: Select installation directory
Path Config

Select the target installation directory (default recommended: C:\wamp64 or C:\wamp).

Step 5: Complete installation and launch
Launch

Complete the setup wizard, choose your default web browser and text editor when prompted, and start WampServer from the desktop shortcut.

Step 6: Verify WampServer tray icon status
Status Monitor

Observe the WampServer "W" icon in the Windows notification area (system tray). Wait until the icon turns completely GREEN.

RED ICON
All services stopped
ORANGE ICON
1 service running (partial)
GREEN ICON
All services online (Apache + MySQL)
Step 7: Open http://localhost in the browser
Verification

Open your browser and navigate to http://localhost to view the WampServer Dashboard, installed versions, and phpMyAdmin link.

Key Takeaways

Quick Revision Flashcards

Concise 1–2 sentence summaries of every core stack component for rapid review and exam preparation.

Operating System

Linux

An open-source, Unix-like operating system that serves as the secure, stable foundation for LAMP hosting environments.

Powers over 70% of public Internet web servers.
Operating System

Windows

Microsoft's graphical operating system that provides a comfortable local development base for WAMP installations.

Allows building web apps natively on desktop Windows.
Web Server

Apache

The HTTP web server software that accepts client browser requests, delivers static files, and routes PHP scripts.

Listens on Port 80 for HTTP and Port 443 for HTTPS.
Database

MySQL

A robust relational database management system (RDBMS) that stores, queries, and organizes structured site data.

Communicates via SQL queries on default Port 3306.
Language

PHP

A server-side scripting language that executes business logic, queries MySQL, and outputs dynamic HTML to Apache.

Embedded directly within web templates or standalone scripts.
