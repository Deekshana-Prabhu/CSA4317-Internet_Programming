How These Components Work Together

The power of LAMP and WAMP stems from their layered synchronization: The Operating System (Linux/Windows) provisions memory, network sockets, and file system security. The Apache Web Server acts as the public concierge listening on ports 80/443. When a browser requests dynamic content, Apache delegates execution to the PHP interpreter. PHP connects to the MySQL database on port 3306 using structured SQL, extracts requested records, merges data into HTML templates, and passes the generated web page back to Apache, which serves the final HTTP response to the client.

The Request-Response Lifecycle Flow

Visual step-by-step flow from user browser request to final rendered page:

1
User Enters URL
User enters a website address (e.g. http://localhost/profile.php) in the client web browser.
2
Browser Sends Request
Browser translates the domain name via DNS and transmits an HTTP GET/POST request across the network.
3
Apache Receives Request
Apache listens on Port 80 (HTTP) or 443 (HTTPS), parses incoming HTTP headers, and identifies the target resource.
4
Static vs. Dynamic Routing
Apache serves static files (.html, .css) directly from disk, or forwards executable .php files to the PHP module.
5
PHP & MySQL Processing
PHP processes application code and queries MySQL on Port 3306 for necessary records, generating output HTML.
6
Response Delivered
Apache packages the rendered HTML with HTTP 200 OK headers and transmits the response back to the client browser.
Apache ↔ PHP Integration

How Apache Communicates with PHP

Apache connects to PHP primarily through two proven integration architectures:

  • mod_php (Embedded Apache Module): The PHP interpreter runs inside Apache's worker processes. Fast execution with zero IPC overhead, common on traditional LAMP/WAMP installations.
  • PHP-FPM (FastCGI Process Manager): Apache acts as a reverse proxy, delegating requests to a separate PHP daemon via Unix domain socket or TCP port 9000. Provides superior concurrency and memory isolation.
PHP ↔ MySQL Integration

How PHP Communicates with MySQL

PHP connects to the MySQL server engine using native client library drivers:

  • PDO (PHP Data Objects): A database abstraction layer providing secure prepared statements, SQL injection prevention, and standardized transaction management across databases.
  • MySQLi Extension: A dedicated driver built specifically for MySQL, supporting procedural and object-oriented syntax, dual query caching, and binary protocol statements over port 3306.
Deep Dive: Apache Configuration Files (httpd.conf & apache2.conf)

Apache's behavior is controlled by core configuration files located at /etc/apache2/apache2.conf (on Ubuntu/Debian) or httpd.conf (in WampServer):

  • DocumentRoot: Defines the public web root directory (default: /var/www/html on Linux, C:\wamp64\www on Windows).
  • DirectoryIndex: Prioritizes default landing files (e.g., DirectoryIndex index.php index.html).
  • Listen Directive: Configures network listening ports (e.g. Listen 80 for HTTP and Listen 443 for SSL/TLS).
  • Virtual Hosts: Allows a single Apache instance to host dozens of independent domain names with distinct document roots.
Deep Dive: PHP Engine Configuration (php.ini)

The PHP runtime behavior is managed through the central php.ini configuration file:

  • extension=mysqli & extension=pdo_mysql: Must be enabled to allow PHP to open connections to MySQL.
  • memory_limit: Controls maximum RAM consumption per script execution (e.g. 128M or 256M).
  • upload_max_filesize & post_max_size: Dictates the maximum payload allowed when users upload files via HTML forms.
  • display_errors: Set to On during local development in WAMP, but disabled in production LAMP for security.

Installation & Configuration Guides

Complete, tested step-by-step procedures for Ubuntu Linux (LAMP) and Microsoft Windows (WAMP) with copyable terminal commands, verification, and configuration details.

Ubuntu Linux Installation Checklist
Check off commands as you execute them

Step 1: Update packages
Terminal

Synchronize the package repository index to ensure the latest versions are fetched.

sudo apt update
Step 2: Install Apache
Web Server

Install the Apache2 web server daemon and default configuration files.

sudo apt install apache2
Step 3: Install MySQL
Database

Install MySQL server for relational database storage and user records.

sudo apt install mysql-server
Step 4: Install PHP
Language & Modules

Install the PHP runtime, the Apache integration module, and the MySQL database driver.

sudo apt install php libapache2-mod-php php-mysql
Step 5: Restart Apache
Systemctl

Restart the Apache service to load the newly installed PHP module into memory.

sudo systemctl restart apache2
Step 6: Test installation
Verification

Open http://localhost in your web browser. You should see the standard Apache2 Ubuntu Default Welcome Page.

Essential LAMP Post-Installation Configuration

1. Verify PHP Integration: Create a test script /var/www/html/info.php containing <?php phpinfo(); ?> and visit http://localhost/info.php to confirm all modules.

2. Secure MySQL Installation: Execute sudo mysql_secure_installation to set a root password, remove anonymous users, and disallow remote root login.

3. Set Web Root Permissions: Run sudo chown -R www-data:www-data /var/www/html to grant Apache proper read/write ownership.

Windows WampServer Checklist

Step 1: Download WampServer
Download

Download WampServer from its official portal. Choose the 64-bit (x64) or 32-bit (x86) version matching your Windows OS.

Install the required Microsoft Visual C++ redistributables (VC9 through VC17). Apache and PHP Windows binaries require these runtimes.

Setup Wizard

Step 4: Select installation directory
Path Config

Select the installation directory (default recommended: C:\wamp64 or C:\wamp).

Step 5: Complete installation and launch WampServer
Launch

Complete the setup wizard, select your preferred default web browser and text editor, and start WampServer.

Step 6: Wait until the WampServer icon indicates services are running
Status Monitor

Look at the WampServer icon in the Windows notification area (system tray). Wait until it turns completely GREEN.

RED ICON
All services stopped
ORANGE ICON
1 service running (partial)
GREEN ICON
All services online (Apache + MySQL)
Step 7: Open http://localhost in the browser
Verification

Open your browser and navigate to http://localhost to view the WampServer Dashboard, PHP version information, and phpMyAdmin.

Essential WAMP Configuration & Port Troubleshooting

1. Resolving Port 80 Conflicts (IIS / Skype): If WampServer remains Orange, another program (like IIS or Skype) is using port 80. Left-click WampServer icon → Apache → httpd.conf, change Listen 80 to Listen 8080, and access via http://localhost:8080.

2. Web Document Root: Place your PHP website projects into C:\wamp64\www\myproject\ and access them at http://localhost/myproject/.

3. Accessing Database GUI (phpMyAdmin): Open http://localhost/phpmyadmin. The default username is root with no password (blank).
