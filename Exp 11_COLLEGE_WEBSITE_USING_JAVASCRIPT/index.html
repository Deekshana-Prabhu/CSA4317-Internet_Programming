Technical Architecture

How It Works

JavaScript event-driven programming handles user inputs and updates the Document Object Model (DOM) seamlessly.

onclick Event

Click Interaction

Changes paragraph appearance when a button is clicked. Event listeners attached via addEventListener('click', handler) detect clicks on styling buttons to cycle through fonts, colors, background tints, and sizes.

button.addEventListener('click', () => {
  paragraph.style.fontFamily = newFont;
});
mouseover Event

Hover In Interaction

Highlights a word when the mouse enters it. The listener detects when the cursor passes over individual keyword spans, dynamically applying a bright highlight background and bold typography.

word.addEventListener('mouseover', () => {
  word.classList.add('highlighted');
});
mouseout Event

Hover Out Interaction

Removes highlighting when the mouse leaves it. The listener triggers as the mouse cursor exits the boundary of the keyword, cleanly restoring its original appearance and updating activity counters.

word.addEventListener('mouseout', () => {
  word.classList.remove('highlighted');
});
