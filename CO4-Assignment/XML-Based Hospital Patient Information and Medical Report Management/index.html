XML Validation Architecture: Well-Formed vs. Schema Valid

1. Well-Formed XML Document

Follows standard W3C XML syntax: single root element (<hospital>), properly closed and nested tags, case-sensitive names, and quoted attributes.

2. Valid XML Document (XSD)

Conforms strictly to patients.xsd: data types (integer age 0-125), enumeration facets (valid departments, blood groups, gender), and identity constraints (xs:unique on patient ID).

3. XML Parsers & Error Detection

Detects structural errors (fatal syntax break) and validation violations. Implemented in PHP via DOMDocument::schemaValidate() and in browser memory via JS Schema Engine.
