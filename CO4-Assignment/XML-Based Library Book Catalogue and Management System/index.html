XML Validation Engine (DTD & XSD)

Validate XML structure and constraints using both Document Type Definition (DTD) and W3C XML Schema Definition (XSD).

Document Type Definition (DTD)

books.dtd

Defines the legal building blocks of books.xml: declares the root element <!ELEMENT library (book+)>, required sequence of child tags, and mandatory id ID #REQUIRED attribute.

W3C XML Schema (XSD)

books.xsd

Provides strict datatype enforcement: xs:decimal with minExclusive="0.00" for price, \\d{4} positive integer for year, and regex pattern matching for 10/13-digit ISBNs.

Comparative Analysis: DTD vs. XML Schema (XSD)

Understanding the architectural and functional distinctions between Document Type Definitions and XML Schemas.

Feature / Dimension DTD (Document Type Definition) XSD (XML Schema Definition) Architectural Advantage
Syntax Proprietary EBNF-like declarative syntax (Non-XML) Written in standard, well-formed XML syntax (<xs:schema>) XSD: Native XML tools apply
Data Types Only character data (#PCDATA, CDATA) Over 44 built-in primitive types + custom facets (patterns, ranges) XSD: Strict type safety
Occurrence Rules Basic quantifiers (?, *, +) Exact numeric constraints via minOccurs and maxOccurs XSD: Precise cardinalities
Namespaces No native support for XML namespaces Full native support for multi-namespace qualification XSD: Enterprise namespace isolation
Extensibility Rigid; cannot inherit or extend types Inheritance and derivation via extension & restriction XSD: Object-oriented modeling
Ease of Use Simple, compact, and quick to write More verbose; requires formal namespace declarations DTD: Lightweight & simple
Summary Takeaway: DTD establishes basic structural boundaries (document hierarchy, allowed elements, and required attributes), whereas XSD provides deep structural, data-type, cardinality, and facet validation essential for modern data interchange.

JavaScript XML DOM (Client-Side) DOMParser & XMLSerializer 
// 1. Parse XML String
const parser = new DOMParser();
const doc = parser.parseFromString(xmlStr, "text/xml");

// 2. Query Elements
const books = doc.getElementsByTagName("book");
const book = doc.querySelector("book[id='B001']");

// 3. Mutate Element
book.getElementsByTagName("price")[0].textContent = "500";

// 4. Create & Append Element
const newElem = doc.createElement("book");
newElem.setAttribute("id", "B013");
doc.documentElement.appendChild(newElem);
PHP DOMDocument (Server-Side in index.php) DOMDocument & DOMXPath 
<?php
// 1. Load XML File
$dom = new DOMDocument();
$dom->load('books.xml');

// 2. Query Elements via XPath
$xpath = new DOMXPath($dom);
$books = $xpath->query("//book[@id='B001']");

// 3. Mutate Element
$books->item(0)->getElementsByTagName('price')
      ->item(0)->nodeValue = "500";

// 4. Create & Append Element
$newBook = $dom->createElement('book');
$newBook->setAttribute('id', 'B013');
$dom->documentElement->appendChild($newBook);
$dom->save('books.xml');
?>
